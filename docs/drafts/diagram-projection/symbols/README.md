# Electrical symbol specimen sheet

Serve the parent `diagram-projection` directory over HTTP, then open
`http://127.0.0.1:8765/symbols/`. For example, from that directory:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

No build or network dependencies. ES modules require HTTP; opening the HTML as a
local file is not supported. Fonts and base theme styles are shared with the
feeder gallery.

## Review controls

- **Equipment / Equivalent circuit / Compare** selects the drawing detail.
- **Paper / Dark** selects the surface; **Monochrome** removes chromatic accents
  in either theme without changing geometry or meaning.
- **Export sheet SVG** downloads the current representation and resolved palette.
  Source and port identifiers, model assumptions in SVG descriptions, and vector
  geometry survive export. Fonts use local monospace fallback, not embedded assets.
- View, theme and colour are encoded in the URL. Print uses black-on-white symbols.

Example: `?view=compare&theme=dark&colour=mono`.

Nine specimens cover seven equipment families: π line, generator, external
supply, constant-power load, two-winding transformer, capacitive shunt and a
switch shown closed, open and unknown. Each card states the exact illustrative
model boundary. The sheet is an engineering review fixture, not a standards
compliance claim or an inferred representation of a BMOPF network.

## Registry contract

`symbols.mjs` owns authored primitives and external ports; `app.mjs` only selects
representations, resolves the palette, renders cards and exports them. Both use
the same glyph renderer. Each specimen contains:

- A stable fixture `id`, equipment `kind`, optional switch `state`, and title.
- One external `ports` array with local ID, position, label and terminal/reference
  role, shared by equipment and equivalent views.
- Separate equipment/equivalent primitive lists and captions, plus an explicit
  model assumption description.

The shared local bounds are `380 × 200` drawing units. SVG paths, circles,
rectangles and text use role-based styles. `data-source` and `data-port` are review
identities, not imported PowerIO references. Internal model reference nodes are
local annotations, not additional external terminals or physical earth bonds.
The registry describes a visual specimen; it is not an electrical connectivity
solver or production TypeScript contract.

## Engineering review

Check that the π line preserves independent end admittances; generator and supply
remain distinct; the constant-power load is not represented as a resistance;
transformer primary and secondary have no conductive bridge; and switch position
is unambiguous without colour. Every equivalent is a declared scalar study model.
A multi-wire model needs actual conductor matrices, winding connections, reference
semantics and per-pole switch state. It must not be generated by copying these
scalar drawings once per phase.

Browser review covers stacked narrow cards and desktop comparison/grid layouts,
both representations, both themes, monochrome, URL restoration and portable SVG
export. Useful regression checks when editing the registry: stable source/port
IDs across views; valid SVG without external CSS dependencies; labels and geometry
within bounds; and unchanged meaning when colour is removed.

The scale experiment remains in `../performance/`. Before integrating symbols
there, convert approved primitives into batched GPU geometry, reserve symbol and
label bounds during routing, and expose equivalent detail only within a bounded
inspection scope. This sheet makes no new performance claim for 100k buses.
