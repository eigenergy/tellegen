Conventions, scope and next steps

Symbols use an IEC-oriented vocabulary for review; this sheet is not a standards compliance claim. The load arrow denotes demand equipment, not a solved flow direction. A π line’s end admittances need not be equal. Generator and supply models are explicitly chosen examples. Transformer coupling is a magnetic annotation, never a conductor. Switch position is separate from service availability.

These scalar equivalents do not elaborate conductor coupling, winding connections or per-pole state for a multi-wire network. Those require authoritative source semantics. Breakers, disconnectors, motors, inverter models, inductive shunts and physical grounding arrangements need distinct approved specimens.

Equipment and circuit models share a small local vector registry with explicit external ports. Geometry is manually authored; there is no automatic layout or 100k-bus symbol renderer here. The performance gallery remains the scale experiment. Export resolves the current palette and preserves source/port identifiers; fonts are referenced, not embedded. The SVG includes per-specimen assumption descriptions.
