      What this benchmark measures

      The synthetic fixtures use precomputed schematic layouts. BMOPF datasets retain source bus and equipment identities in all three layouts. Leaf order and Tidy tree use the same source-rooted spanning forest and orthogonal routes computed offline; Source coordinates provides the geographic reference. Leaf order gives every leaf a separate row; Tidy tree packs shorter branches into unused space. The combined SAPN collection places five independent networks in separate panels, without adding electrical connections. Transformer associations do not imply conductor continuity across windings. In the coordinate reference, co-located equipment uses small display detours. Both schematic placements separate buses while retaining original coordinates in the inspector. Equipment + clearance adds precomputed transformer and switch bodies plus load, general-shunt and supply attachments. Reserved routing slots keep foreign routes out of symbol bodies; the larger spacing changes the diagram footprint. Compact mode replaces open switch bodies with endpoint rings and restores a selected switch. Equipment uses binary stroke, junction and hit-target layers; all glyphs remain submitted at every zoom. Buses and wires use two base GPU layers; Fan-out + lanes adds one binary busbar layer. GPU clipping handles off-screen geometry. There is no CPU viewport culling. Fan-out ports belong to their original bus; no electrical nodes are added. Crossing-aware lanes reorders mesh lanes in bounded offline passes while preserving tree-lane order, bus positions, ports and corridor widths. Circuit inspection highlights one enabled non-tree connection and its endpoint-to-endpoint tree path. Schematic layout runs during staging, not during browser interaction. Local labels use a spatial index and a 200-label budget. The optional result overlay adds voltage-limit and loading colours plus bounded local P/Q direction markers. Its status banner distinguishes saved solutions from artificial rendering stress data.

      Load time includes local HTTP fetch and the first deck.gl draw callback, which is not a GPU completion fence. CPU array bytes exclude library copies, GPU allocations, labels, and object overhead.

      Colour modes: threshold views (default) keep the drawing neutral and colour only problems; continuous views show loading as % of rating and voltage as position in each bus's declared band (worst pair).       Sign convention: positive end P/Q enters the equipment at that end, so a branch's two end powers sum to what it consumes (its losses). Voltages are magnitudes of declared terminal-pair differences, compared against declared pair limits; no nominal base is inferred. Unbalance uses magnitudes only: IEEE PVUR for phase–neutral, NEMA LVUR for phase–phase. Loading: amber ≥ 90 %, red > 100 % of the declared rating basis. Profiles follow the display spanning tree, not an inferred unique path through a mesh.
