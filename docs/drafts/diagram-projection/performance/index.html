What this benchmark measures
The synthetic fixtures use precomputed schematic layouts. BMOPF datasets retain source bus and equipment identities in all three layouts. Leaf order and Tidy tree use the same source-rooted spanning forest and orthogonal routes computed offline; Source coordinates provides the geographic reference. Leaf order gives every leaf a separate row; Tidy tree packs shorter branches into unused space. The combined SAPN collection places five independent networks in separate panels, without adding electrical connections. Transformer associations do not imply conductor continuity across windings. In the coordinate reference, co-located equipment uses small display detours. Both schematic placements separate buses while retaining original coordinates in the inspector. Equipment + clearance adds precomputed transformer and switch bodies plus load, general-shunt and supply attachments. Reserved routing slots keep foreign routes out of symbol bodies; the larger spacing changes the diagram footprint. Pick a symbol or find its exact equipment ID to inspect the original source record. Compact mode replaces open switch bodies with endpoint rings and restores a selected switch. Equipment uses binary stroke, junction and hit-target layers; all glyphs remain submitted at every zoom. Buses and wires use two base GPU layers; Fan-out + lanes adds one binary busbar layer. Full routes submits all geometry; Endpoint rings submits cached geometry without open-switch routes, plus grouped endpoint annotations and the selected route. GPU clipping handles off-screen geometry. There is no CPU viewport culling. Fan-out ports belong to their original bus; no electrical nodes are added. Corridor routing may expand depth spacing and busbar clearance. Crossings remain possible. Crossing-aware lanes reorders mesh lanes in bounded offline passes while preserving tree-lane order, bus positions, ports and corridor widths. Corridors with more than 32 lanes, disabled routes or exterior escapes retain their original ordering. Circuit inspection highlights one enabled non-tree connection and its endpoint-to-endpoint tree path, with a contrasting route halo and endpoint markers. Context dimming changes layer opacity; the base geometry stays resident. Fit circuit includes route bends and busbars. The connection selector shows at most 40 results at once; previous/next visits all matches. Schematic layout runs during staging, not during browser interaction. Green marks closed switches; amber gaps mark open or out-of-service branches. Switch state is explicit in the inspector and separate from service status. Endpoint rings suppress long open-switch routes by default; Full routes restores them. The selected open switch always retains its full route and gap. Open switches remain selectable but are excluded from the spanning forest and non-tree circuit browser. MVLVmeshed has no source coordinates: both explicit state scenarios use schematic layouts only. Cyan marks non-tree line connections. Line crossings are not junctions; source endpoints are authoritative. Local labels use a spatial index and a 200-label budget. Amber marks sources, layout roots and disabled/open branches; violet marks transformer associations; other colours are neutral drawing styles. The optional result overlay adds voltage-limit and loading colours plus bounded local P/Q direction markers. Its status banner distinguishes saved solutions from artificial rendering stress data.
Load time includes local HTTP fetch and the first deck.gl draw callback, which is not a GPU completion fence. CPU array bytes exclude library copies, GPU allocations, labels, and object overhead. See the benchmark guide and 100k-bus design for limitations and production requirements.
