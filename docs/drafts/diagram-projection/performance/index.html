What this benchmark measures

The synthetic fixtures use precomputed schematic layouts. BMOPF datasets retain source bus and equipment identities in all three layouts. Leaf order and Tidy tree use the same source-rooted spanning forest and orthogonal routes computed offline; Source coordinates provides the geographic reference. Leaf order gives every leaf a separate row; Tidy tree packs shorter branches into unused space. The combined SAPN collection places five independent networks in separate panels, without adding electrical connections. Transformer associations do not imply conductor continuity across windings. In the coordinate reference, co-located equipment uses small display detours. Both schematic placements separate buses while retaining original coordinates in the inspector. Buses and wires use two base GPU layers; Fan-out + lanes adds one binary busbar layer. All geometry is submitted; GPU clipping handles off-screen geometry. There is no CPU viewport culling. Fan-out ports belong to their original bus; no electrical nodes are added. Corridor routing may expand depth spacing and busbar clearance. Crossings remain possible. Circuit inspection highlights one enabled non-tree connection and its endpoint-to-endpoint tree path, with a contrasting route halo and endpoint markers. Context dimming changes layer opacity; the base geometry stays resident. Fit circuit includes route bends and busbars. The connection selector shows at most 40 results at once; previous/next visits all matches. Schematic layout runs during staging, not during browser interaction. Cyan marks non-tree line connections. Line crossings are not junctions; source endpoints are authoritative. Local labels use a spatial index and a 200-label budget. Amber marks sources, layout roots and disabled/open branches; violet marks transformer associations; other colours are neutral drawing styles. No voltage or phase overlay is shown.

Load time includes local HTTP fetch and the first deck.gl draw callback, which is not a GPU completion fence. CPU array bytes exclude library copies, GPU allocations, labels, and object overhead. See the benchmark guide and 100k-bus design for limitations and production requirements.
