What this benchmark measures

These are synthetic single-line bus/branch fixtures with precomputed coordinates, not solvable PowerIO cases. All buses and route segments are submitted in two base GPU layers; GPU clipping handles off-screen geometry. There is no CPU viewport culling or automatic layout. Local labels use a spatial index and a 200-label budget. Amber marks region roots and open ties; other colours are neutral drawing styles. No voltage or phase overlay is shown.

Load time includes local HTTP fetch and the first deck.gl draw callback, which is not a GPU completion fence. CPU array bytes exclude library copies, GPU allocations, labels, and object overhead. See the benchmark guide and 100k-bus design for limitations and production requirements.
