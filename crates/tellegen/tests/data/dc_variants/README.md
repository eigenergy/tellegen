# DC variant regression fixture

`case3_variants.m` is an original synthetic MIT-licensed fixture for #206.
It includes resistance, a nonunity transformer tap, a phase shift, congestion
and strictly convex generator costs with constant terms.
`case3-reference.json` is generated by PowerModels 0.19.9 with Ipopt from this
fixture, using the reproducible environment and scripts in
`evals/dc-variants/` at the repository root. DCP and DCMP use built-in models;
the other three use explicit independent extensions. No third-party network
data is vendored in this directory.
